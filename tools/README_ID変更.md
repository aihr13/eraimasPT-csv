# キャラIDの変更

Python 3（追加パッケージ不要）を使用します。

1. `character_id_map.csv` を開き、キャラ名を見ながら「変更後ID」に希望の番号を入力します。編集用CSVは「キャラ名・変更後ID」の2列です。キャラ名は変更しません。現在IDは実行時にキャラCSVの名前から自動判定します。空欄または現在と同じIDなら変更しません。
2. リポジトリ直下で `python3 tools/rename_character_ids.py` を実行し、変更予定を確認します。
3. `python3 tools/rename_character_ids.py --apply` で反映します。

変更対象は `chara/` 以下のファイル名の数字・番号欄・数値指定の相性（`;相性`を含む）・数値指定のCSTR参照、および `CSTR.csv` のID（1000＋キャラID）です。名前指定の参照や体力などの数値は変更しません。元のBOM・改行・コメントを保持します。サブフォルダの移動はしません。

IDは0～999で指定します。ID交換は両方の行に変更後IDを記入してください。置換は同時に行います。既存キャラとの番号重複やCSTRとの不一致は書き込み前にエラーになります。

反映前の全変更ファイルと使用リストを `id_backups/日時/` に保存します。実行中の通常の書き込みエラーでは元に戻します。反映済みのリストを再実行しても、現在IDと変更後IDが一致するため再変更しません。

このツールは `chara/` と `CSTR.csv` のみを対象にします。他のフォルダ・スクリプト・セーブデータにあるID参照は変更しません。
